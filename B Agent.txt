# B AGENT — MASTER BUILD SPECIFICATION

## Build a complete Android-native autonomous AI Agent

You are not building a chatbot.

You are not building a UI mockup.

You are not building a frontend for a remote AI.

You are not building a simplified AI assistant.

You are building a COMPLETE, REAL, INSTALLABLE, ANDROID-NATIVE AUTONOMOUS AI AGENT called:

# B Agent

The final deliverable MUST be a production-oriented Android application that can actually be compiled, installed, launched, configured, and used on a real Android device.

The application should be conceptually comparable to modern coding/computer agents such as OpenCode, Claude Code, Codex CLI, Gemini CLI, and similar agentic developer systems, while adapting the architecture to Android's actual security and operating-system constraints.

The goal is to create the strongest practical general-purpose AI Agent possible on Android.

Do not intentionally simplify the architecture merely to make development easier.

If a feature requires additional dependencies, runtimes, binaries, libraries, services, or optional components, design the system to install/configure them automatically when legally and technically possible.

If Android prevents a capability, detect that limitation honestly and implement the strongest available fallback.

6. REAL AGENT LOOP
==================

Implement a real iterative agent loop.

Pseudo-flow:

while task_not_finished:

```
observe_environment()

build_context()

ask_model()

validate_model_response()

if tool_call:
    validate_tool()
    check_permission()
    execute_tool()
    capture_result()
    add_observation()
    continue

if final_answer:
    verify_completion()
    finish()
```

The Agent must be able to perform hundreds of tool interactions when required.

Do not impose an arbitrary low number of steps.

Make maximum iterations configurable.

Provide safeguards against infinite loops.

Example defaults:

maximum_iterations:
100

maximum_same_action_retries:
5

maximum_tool_runtime:
configurable

maximum_session_runtime:
configurable
